# مبینا — دموی سایت مربی و شاگرد

این پروژه با React و Vite ساخته شده و روی GitHub Pages منتشر می‌شود:

https://aysahajipour.github.io/mobina-coach/

## اجرای محلی

```bash
npm ci
npm run dev
```

## انتشار

```bash
npm run build
```

خروجی در `docs/` ساخته می‌شود. فایل‌های `docs/` را همراه با تغییرات منبع روی شاخهٔ `main` ثبت و ارسال کنید؛ GitHub Pages از پوشهٔ `docs/` همین شاخه منتشر می‌کند.

این نسخه دمو است: داده‌های فرم و عکس‌ها فقط در حافظهٔ مرورگر نگه داشته می‌شوند و به سرور ارسال یا ذخیره نمی‌شوند.
